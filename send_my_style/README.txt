SendMyStyle Customer Web MVP — Pure HTML + Tailwind + JavaScript

Files:
- index.html — complete responsive interactive customer storefront prototype.

Run:
1. Open index.html directly in a browser, or use VS Code Live Server.
2. Tailwind is loaded through the CDN for prototyping.
3. Product/cart/wishlist state is stored in localStorage.

Included routes:
/, /shop, /product/:id, /customize/:id, /cart, /checkout, /success, /wishlist, /profile, /orders, /login, /search

Notes:
- Images are temporary remote Unsplash images for the prototype.
- Replace image URLs and demo product data with your API later.
- For production, compile Tailwind instead of using the CDN.
